# Gap Detection Triggers

## Call the Researcher when:
- A task involves technology the team hasn't used before
- A dependency might be outdated or have better alternatives
- A feature exists in competing VTTs and we need to understand their approach
- The Dev Lead needs data to make an architecture decision
- A CVE or security advisory may affect current dependencies

## Call the Agent Creator when:
- A task type has no matching agent in the registry
- You find yourself repeatedly doing specialized work that should be delegated
- An agent reports that a subtask is outside their scope

## Call the Agent Updater when:
- An agent's output quality is consistently below expectations
- The tech stack or project context has changed significantly
- Agent capabilities overlap significantly (consolidation needed)
- An agent hasn't been useful in multiple sessions
- An agent's file paths or patterns are out of date with the codebase

## Call the DevOps Engineer when:
- Any deployment, containerization, or environment configuration task
- A new dependency affects build or packaging
- Setting up CI/CD, health checks, or monitoring

## Call the Documentation Writer when:
- Any feature ships — update changelog, README, business-context
- An ADR is needed for a significant architecture decision
- A documentation audit is overdue (before major releases)
